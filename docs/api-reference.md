# API reference

Generated from the source of each engine at release, one reference per library. Every one of them documents the same contract; what differs is the language.

| Library | Reference | Generated by |
|---|---|---|
| **SwiftUI** · `MilanoSDK` | [swiftui](libs/swiftui/) | DocC |
| **Compose** · `dev.get-milano:engine-compose` | [compose](libs/compose/) | Dokka |
| **TypeScript** · `@get-milano/core` | [ts](libs/ts/) | TypeDoc |
| **React** · `@get-milano/react` | [react](libs/react/) | TypeDoc |

These track the latest release. For the API of an older version, read it from that version's tag in the [repository](https://github.com/get-milano/sdk/tags).

The guides on this site are the place to start: [Getting started](getting-started) installs an engine and renders a document, and [Creating a bridge](bridge) connects Milano to your design system. The references above are for looking up a specific type once you are building.

## Generating them locally

```sh
./scripts/generate-docs.sh
```

Writes all four into `docs/libs/`, which is generated output and never committed. Xcode is required for the DocC lane; without it that one is skipped and the other three still run.
